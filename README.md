A program that writes one startup pitch sentence — ad space on the bottom of swimming pools — to `/output/entry.txt`. The line is 152 characters, one sentence, UTF-8, no trailing newline. Deterministic: two runs write byte-identical files. No network, no dependencies outside this repository.

## Run it

```sh
python3 main.py
```
